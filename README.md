# lista-de-atendimento
Este projeto consiste no desenvolvimento de um Simulador de Fila de Atendimento com Prioridade Estável e Persistência. O sistema gerencia o fluxo de atendimento de pessoas baseado em dois critérios de ordenação: o nível de prioridade (onde maior prioridade tem preferência) e a ordem de chegada (garantindo que, sob a mesma prioridade, o atendimento seja estritamente cronológico, característica conhecida como ordenação estável).
